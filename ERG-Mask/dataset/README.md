# ERG-Mask Dataset

This repository contains dataset files associated with the ERG-Mask study, including grape-cluster images, corresponding annotation files, and edge JSON decoding/conversion files. These files provide the necessary dataset components for reproducing the ERG-Mask training and evaluation workflow reported in the study and are provided for academic research purposes.

The images folder contains grape-cluster images. The annotations folder contains the corresponding annotation files, including edge-label PNG files, label visualization files, and label-name information. The edge_json_decode folder contains files related to edge JSON decoding or conversion.

A portion of the data used in the study was provided by collaborators. We are actively communicating with the data provider regarding permission for public sharing and will update this repository once permission is obtained.
