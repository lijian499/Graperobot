# ERG-Mask Dataset

This folder contains the currently shareable dataset files associated with the ERG-Mask study, including grape-cluster images, corresponding annotation files, and edge-related JSON decoding files. These files are provided for academic research and for reproducing the ERG-Mask training and evaluation workflow.

The `images` folder contains grape-cluster images. The `annotations` folder contains the corresponding annotation files, including edge-label PNG files, label visualization files, and label-name information. The `edge_json_decode` folder contains files related to edge JSON decoding or conversion. The `example` folder provides example files for reference.

Some data used in the study were provided by collaborators. We are actively communicating with the data provider regarding permission for public sharing and are working to make the remaining shareable data available as soon as permission is confirmed.
