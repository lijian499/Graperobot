# ERG-Mask Dataset

This folder contains the currently shareable dataset files associated with the ERG-Mask study, including grape-cluster images, corresponding annotation files, and edge-label PNG files. These files are provided for academic research and for reproducing the ERG-Mask training and evaluation workflow.

The `images` folder contains grape-cluster images. The `annotations` folder contains the corresponding annotation files. The `edges` folder contains the corresponding edge-label PNG files.

Some data used in the study were provided by collaborators. We are currently communicating with the data provider regarding permission for public sharing. These data will be shared only after permission is obtained from the data provider.
